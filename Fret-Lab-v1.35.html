How to use

Fret Lab trains note names on the neck, staff, and tab — with short games.

  1. Pick a Method (1 → 2 → Rhythm → 3) or a Game.
  2. Use Practice to learn, then Test me with answer taps (mic later).
  3. Multi-location asks for every fret of the same pitch — not one pitch = one fret.
  4. Key / family / mode hand off from Mode Lab via the header pills.
  5. Scale exercises use that handoff: degrees, next-in-scale, and all tones in frets 0–4.
  6. Staff and tab transfer both ways; tab is not a substitute for the staff.
  7. Use Neck · Score · Both to fill the screen. Score Play hears the demo via alphaSynth.
  8. Open in Mode Lab / Jam this scale keep the same key.
