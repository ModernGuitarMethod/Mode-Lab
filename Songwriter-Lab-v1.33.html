How to use

  1. Pick Key. Same key as the other labs if you came from a header pill.
  2. Tap a family, then tap a mode. Header pills Mode · Jam · Chord · Song · Player keep that key with you.
  3. Add sections with the chips (Verse, Chorus…). Pick a section in Brainstorm.
  4. Write words for that section, one line per bar. They copy onto the lead sheet. Do not retype them there unless you are spacing a line under a bar.
  5. 5W+H is about the song, not a section.
  6. Tap a chord chip, then tap a beat on the bar. Chords sit above the lyrics. Default snap is quarter notes (up to four changes per bar). Use Snap 8ths only if you need it.
  7. Space the lyric text under the bar so it lines up with the chords.
  8. Fill Copyright belongs to, writers, participants, and band. Print / Save PDF prints a white C lead sheet. Work saves in this browser.
