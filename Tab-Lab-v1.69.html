How to use

The cream page is alphaTab — same engine family as Guitar Pro: notation + tab, chord diagrams, bends, player.

One view switch: Tab (default) · Notation (staff) · Both (staff above tab — lead-sheet mate with Song Lab). NotePad at the bottom is the only edit surface.

Tap a part on the strip to read its tab (or notation), or All to see every instrument on one concert score.

Import

  1. Best: Guitar Pro .gp / .gpx — richest bends, tab, diagrams.
  2. MuseScore: File → Export → MusicXML. Prefer .musicxml or compressed .mxl. Use a Guitar + Tab template so string/fret is in the file.
  3. Drop the file on this page or use Upload. Play uses the built-in soundfont.
  4. If MuseScore exported linked score+tab as two parts, pick the guitar track. Leave part-groups unmerged so a piano grand staff stays two staves.

Edit + bends

  1. NotePad pad is always on screen. D-pad moves the cursor; type frets or tap 0–9 (two-digit buffer).
  2. Tap Bend to cycle ½ tone · full · release · prebend (drawn as GP arrows, sounding in the player).
  3. Instrument / Sound on the top strip switch guitar, bass, drums, keys and GM voice.
