Guitar Lab

Suite v1.39

One folder. Six labs. Same header, same 1100 / 100dvh frame, same key–family–mode handoff. Open Mode Lab first on an iPad, or pick a lab below.

Mode Lab

Modes of any key, neck + staff, practice and Test Me with a four-beat count-in and green tempo flash.

Jam Lab

Backing loops in the current key / mode / genre. Hands off the same query as Mode Lab.

Chord Lab

Grips and Test Me tone check. Same suite shell as Mode and Jam.

Song Lab

Lead sheet. Time signature and tempo write through to Tab Lab so the empty tab session matches the chart.

Tab Lab

Player + editor. GP / MusicXML / AlphaTex. Transport, tools, and Song Lab meter sync.

Fret Lab

Staff→neck games plus scale studies: threes, pyramid, and broken thirds on every family/mode.
